# imohseni — Rubika Copier

نصب با یک دستور (روی سرور اوبونتو، با کاربر root):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mehrantiz74-a11y/imohseni/main/rubika-install.sh)
```

بعد از اجرا منوی فارسی باز می‌شود: نصب، آپدیت، بکاپ، بازیابی، وضعیت، نمایش مشخصات، ریست نام کاربری و رمز، حذف.

بعد از نصب، ورود به تلگرام و روبیکا را از داخل پنل انجام بده.
